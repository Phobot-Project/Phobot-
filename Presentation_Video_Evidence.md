# PHOBOT Final Presentation Video Evidence

This file provides a record of the final recorded presentation video for the PHOBOT Android-Controlled Kobuki Mobile Robot project.

The presentation video has been uploaded to the GitHub Releases section of this repository.

## Release Details

**Release title:** PHOBOT Final Presentation Video  
**Release tag:** Presentation_PHOBOT  
**Uploaded file:** PHOBOT_Presentation.mp4  
**Release status:** Latest release  

## Purpose of the Video

The video was prepared as a replacement for the cancelled in-person presentation. It explains the final project work, technical implementation, testing evidence, and future improvements.

## Video Content

The presentation covers:

- Project aim and overview
- Android controller app demonstration
- USB communication problem and fix
- Kobuki binary packet protocol
- FTDI serial chip initialisation
- USB, Bluetooth, and WiFi connection architecture
- Voice command support
- Working demonstration and test results
- Project limitations
- Future work

## Evidence Note

This release is included as supporting evidence for the Group Project submission. It demonstrates the team’s final implementation and the technical contributions made during the PHOBOT project.
